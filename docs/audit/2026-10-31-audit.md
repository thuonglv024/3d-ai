## 3. How the 3D body is made
- Two silhouettes → **three girths + W/D ratios** on an Anny base. No shape-parameter optimisation: weight from waist/height, muscle fixed 0.45 (`anny_body.py:63-75`); only the mesh is scaled to targets (`measurements.py:284-359`).
- Pixels ÷ `shared_height` × `height_cm` (`measurements.py:49`); metres (`anny_body.py:111-121`). Height self-reported; upper-body assumes 0.195/0.290 H (`reconstruction.py:113-144`).
- Personal: 3 girths + W/D. Neck/thigh/calf/ankle fixed elasticities (`proportions.py:17-22`); head, arms, feet, posture template. Else near average.

## 4. Measurements from the mesh
- `mesh_plane` cut → closed loop → **Euclidean segment sum** (`measurements.py:78-126`); no geodesic/convex hull.
- Levels = fractions of shoulder→hip (.30–.44/.52–.78/.95–1.02; `measurements.py:53`), template joints ≈.805/.534 (`anatomy.py:84-129`); no chest/waist landmark, max/min circumference in a band.
- Shoulder = 2D landmark distance × height (`measurements.py:54`); arm/inseam `unavailable` (`report.py:127-128`); neck/head/thigh/calf/ankle fixed `.855/.955/.405/.235/.065` (`report.py:115-121`).
- Reported chest/waist = ellipse estimate, not mesh perimeter (`report.py:109-112`); mesh forced to it. Hardcoded factors/bands/levels/coefficients.

## 9. Top 7 issues (impact order)
1. **Parametric prior, not reconstruction.** Only 3 girths + W/D; arms, shoulders, legs, posture, fat distribution are average Anny (`reconstruction.py:595-623`, `anny_body.py:63-75`). Root cause: 2D silhouette → 3 scalars.
2. **Ellipse × hardcoded concavity factors.** Chest +8.07%, waist +3.21%, hip +6.23% not population-derived; “fit error 0.0” is mesh-vs-ellipse only (`measurements.py:20-24,43-75`).
3. **Scale from self-reported height.** ±5 cm ≈±3% circumference (`test_photo_measurements.py:163-186`); upper-body assumes 0.195/0.290 H (`reconstruction.py:113-144`).
4. **Fit-map invents garment.** Body-range midpoint + fit-label ease (`fitmap.py:141-156`); only 2 SKUs have flat specs, chest only (`catalog_seed_data.py:327-369`). Lower-edge body → “loose” though `recommend_size` fits.
5. **Clothing/arms contaminate silhouette.** +8 px dilation → +6–12 cm chest (`test_photo_measurements.py:163-186`); merged arm run changes section (`camera_fusion.py:201-212`).
6. **Heatmap is categorical.** 3 fixed bands, overlapping waist/hip, arms included (`BodyViewer.tsx:32-47`, `fitmap.py:24-28`); no per-vertex Δ.
7. **No ground truth; AI provenance mixed.** `N_human=0`, `uncertainty_cm=None`; AI mesh labelled `photo_estimate`/`photo_with_prior` (`report.py:109-112`) and uses .72/.60/.5334 (`reconstruction.py:536`).
