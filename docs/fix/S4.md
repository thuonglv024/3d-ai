# S4 — Taubin có ràng buộc vùng cổ-vai, kiểm tra chu vi + rollback

- Bước: 4/8. Nhánh `fix/step4`. `docs/fix/DECISIONS.md` vẫn chưa tồn tại.
- File sửa (3): `backend/app/reconstruction.py`, `backend/app/measurements.py`,
  `backend/tests/test_reconstruction.py`.

## 1. Thay đổi

1. Bỏ Laplacian `volume_constraint=True` + refit toàn phần.
2. Dùng **Taubin** (`lamb=.65, nu=.68, iterations=2`) rồi trộn displacement với trọng số
   vùng: khóa hoàn toàn dải `0.82–0.86 H` (Gaussian tâm `.84`, sigma `.06`), các vùng khác
   giữ 100% smoothing.
3. Không refit lại sau smooth. Đo lại 3 chu vi bằng `measure_target_sections()`.
   Nếu `max_fit_error_cm > 0.5` hoặc mesh không valid → **rollback** trả mesh gốc và `profile=None`;
   caller giữ profile trước smooth.
4. Tách `measure_target_sections()` trong `measurements.py` để dùng chung cho fit và smooth.

- Smooth mới nhanh hơn: 0.31–0.79 s/case.
